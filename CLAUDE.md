# Project Instructions

Read and follow all instructions in @AGENT.md.

Treat `AGENT.md` as the single source of truth for the product, design system, UX rules, component guidance, and implementation constraints.

When working on this project:

- Follow `AGENT.md` before making design or architecture decisions.
- Preserve the visual language and product direction defined there.
- Reuse existing components and patterns before creating new ones.
- Keep implementations mobile-first, accessible, and consistent.
- Do not replace the documented design system with unrelated defaults.
- When requirements conflict, prefer explicit user instructions, then `AGENT.md`.
